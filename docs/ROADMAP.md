# NOVA 开发路线图

- [x] React 产品前端、路由与响应式布局

- [x] 注册、登录、注销、服务端会话与账户资料
- [x] SQLite 用户、会话、项目、对话、消息和文章数据表
- [x] Studio 项目创建、编辑、保存和删除
- [x] Research 搜索、分类、文章详情和管理员 CMS
